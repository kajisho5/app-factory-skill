# ひとこと日記 デザイン設計書（実例・架空のアプリ）

> hig-design-skill の実例です。アプリ名・日記の内容はすべて架空です。モックは `mocks/`（`build.py` で再生成できます）。

## 1. 前提

- アプリの目的： 1日1行だけ日記を書き、あとから読み返せるようにする
- 主な利用者と利用場面： 寝る前や移動中に、片手で短く書きたい人
- 対応プラットフォーム： iPhone / iPhone Duo / iPad / Mac（ネイティブ）/ Apple Watch
- 確認用の画像： 2台並び（pair、一覧と詳細）と、iPhone Duo の端末の枠付き画像。どちらもこのスキルの汎用の枠なので社内の確認用。外部に出すときは Apple の公式の製品ベゼルで作り直す
- 画面の向き： iPhone は縦固定（ウィンドウサイズの変化には追従）。iPhone Duo の外側も縦だけ（1行の日記を書くアプリで、立てて置いて使う場面が少ないため。HIG は横向きの対応を勧めているが、この理由で対応しない）。iPhone Duo の内側はアプリの向きの指定に従わず表示される前提で、横・縦の両方を設計する。iPad は全方向
- 準拠： Apple の Human Interface Guidelines（2026年10月時点）。実装で HIG とぶつかったら HIG を優先し、設計者に報告する。意図して推奨から外す点（iPhone Duo の外側を縦だけ、iPad をサイドバーにする）は §1・§2 に理由つきで書く
- 判断原則： 書くまでの手数を最少にする ＞ 標準の見た目 ＞ 情報量
- 起動画面： S-01 の骨格だけ（背景とカードの形、文字なし、ライト／ダーク別）の Launch Screen。ロゴアニメ・広告なし。起動したら S-01 を表示
- 文言： すべて String Catalogs で管理する前提で設計書に書く
- 通信： 購入（S-04）だけ App Store と通信する。日記は端末内と iCloud の同期だけ
- アプリアイコン： この実例の範囲外
- 照合に使った Apple Design Resources の UI Kit の版： 未使用（寸法は `references/hig-specs.md` の値だけで描いた）

### 流れと確認

| 場面 | 内容 |
|---|---|
| オンボーディング | なし（起動したらすぐ S-01）|
| 権限 | 通知だけ。設定（S-06）で書き忘れ通知をオンにした時点で、説明画面（iPhone・iPhone Duo・iPad は全画面のシート、Mac は設定のウィンドウに付くシート。スワイプで閉じられない。ボタン1つ「続ける」。説明文は左右の余白の中で自動で折り返す）。すでに拒否されている人がもう一度スイッチをオンにしたときは、説明画面を出さず（システムは2回目の許可の画面を出さないため）、スイッチをオフのまま「通知は設定アプリでオンにできます」と「設定を開く」を出す→ システムのダイアログの順に出す。説明の文：「毎晩、その日のひとことがまだのときに1回だけ通知します。時刻は設定で変えられます。」（モックと同じ。通知には Info.plist の文言がないので、この画面で説明する）|
| 削除の入口 | 詳細の削除のボタン（trash。iPhone の S-02 のツールバー、iPad の詳細のツールバー、iPhone Duo の詳細の操作の列）、一覧の行を左にスワイプ、行を長押ししたメニュー（「編集」、区切り、「削除」（末尾・赤））、Mac・iPad は ⌘⌫ と「編集」メニュー |
| 破壊的な操作の確認 | 日記の削除は頻繁な操作ではなく、消えると書き直せないので、アクションシートで確認する（Mac はアクションシートがないので警告のダイアログ。「削除」「キャンセル」／破棄の確認は「破棄」「キャンセル」）（題名「この日記を削除しますか？」、「削除」を上に赤、「キャンセル」を下。iOS 26 では押したボタンの近くから出る）|
| 取り消し | 「取り消す」を押すと、消した日記を元の位置に戻して選んだ状態にする（iPhone で S-02 から消した場合は S-01 のまま、戻った行を一瞬強調する）。削除の後、「削除しました」と「取り消す」（arrow.uturn.backward）を並べた小さな横長の丸い枠を出す。iPhone・iPhone Duo の外側はタブバーの上に浮かせ、一覧と詳細が並ぶ画面と Mac は一覧の上部に出す（ウィンドウの下端には出さない）。約5秒で消えるが、VoiceOver を使っているときは時間で消さず、画面を移るか次の削除まで残し、VoiceOver の「消去」の操作でも消せる。見た目は Liquid Glass の横長の丸い枠（高さ44pt以上、左右の余白16pt、文字 Subhead、「取り消す」の当たり判定44pt）。アクセシビリティの文字サイズでは文言と「取り消す」を2段に積み、枠の高さを伸ばす。iPhone ではシェイクと、テキストの編集メニューの「取り消す」でも戻せる。iPad・Mac は ⌘Z と「編集」メニュー |
| 編集中のシートを閉じるとき | S-03 を開いたときから本文か天気が変わっていたら、スワイプ・キャンセル（xmark）・Mac の esc と「キャンセル」のどれで閉じようとしても、アクションシートで題名「変更を破棄しますか？」、「破棄」（上・赤）と「キャンセル」（下）を出す |
| 課金画面（S-04）| 「ひとこと日記 Pro」の名前、買い切りで定期支払いがないこと、価格（現地通貨）、購入の復元、利用規約とプライバシーポリシーへのリンク。無料トライアルはない。上限の説明と購入は1枚にまとめる。下にスワイプしても閉じられる。購入が成功したら S-04 を閉じ、上限から来た場合はそのまま S-03 を開き、残り件数の表示はすぐ消す。復元が成功したら S-04 を閉じる。上限から来た場合はそのまま S-03 を開き、設定から来た場合は設定の Pro の行を「Pro（購入済み）」にして、「購入を復元しました」を「削除しました」と同じ形の枠で出す |
| 評価の依頼 | システムの依頼画面を、日記を10件保存した後に1回だけ。初回起動中には出さない |
| 状態の保存 | 再起動後も、表示中の画面・一覧のスクロール位置・S-03 の入力中の文章・選択中の日記（iPhone Duo 内側・iPad・Mac）・Mac のウィンドウの位置と大きさを戻す |
| 同期で同じ日の日記が2件になったとき | 両方を残し、その日の詳細に「別の端末で書いた文があります」と出す。押すとシートを開き、2つの文を「この端末」「別の端末」の見出しつきで並べ、それぞれに「こちらを残す」ボタンを置く（見出し・本文・ボタンを1つの区切りにまとめ、VoiceOver ではボタンを「この端末の文を残す」「別の端末の文を残す」と読む）。押すと「別の端末の文（『…』）を削除します」のように消す方をはっきり書いた確認（ボタン「削除」（赤）と「キャンセル」）を出してから消す（黙って消さない。60文字の決まりも守れる）。選ぶまでの間、一覧の行は新しく保存した方の文を出し、日付の横に「2件」と出す（VoiceOver は「10月24日、2件、本文」の順で読む）。件数は2件として数える。Watch はこの端末の文を出す |
| iCloud が使えないとき | S-06 に「iCloud が使えないため、この端末だけに保存しています」と「設定を開く」|
| Pro を買った後 | S-06 の行を「Pro（購入済み）」にして S-04 へは進めない（復元の行は残す）。Mac の「Pro について」は購入済みと表示し、購入ボタンを出さない |
| 書き忘れた日 | カレンダー（S-05）の書いていない日を選ぶと、その日の S-03 を開く（後から書ける）|
| Watch の音声入力 | 「音声で書く」→ システムの音声入力 → 認識した文を確認のシートに出す。60文字を超えたら、超えた部分を淡色で示して「60文字までです」と出し、「保存」を無効にして画面幅いっぱいの「言い直す」ボタンを出す（黙って切らない）。60文字以内なら（左上はシステムの xmark＝「キャンセル」、文の下に画面幅いっぱいの文字のボタン「保存」を1つ）。今日の分がすでにあるときは、確認画面で「今日の分を置き換えます」と出し、ボタンを「置き換える」にする |

### 余白と寸法
- 画面端の余白はシステムのレイアウトマージン（モックでは iPhone 16〜20pt）
- 角の丸み： カード 26pt、その中の選択中の行は同じ中心にそろえて 18pt（＝26 − 余白8）、入力欄 16pt、シートと「削除しました」の枠はシステムの値
- リストはグループ表示（角丸のカード）。セルの高さは2行で約76pt、セル内の左右余白20pt
- 押せる範囲は iPhone・iPhone Duo・iPad・Watch で44×44pt以上。Mac は見た目28×28pt（最小20pt）で、押せる範囲は44ptまで広げる。ツールバーの丸ボタンの間隔は8pt（Liquid Glass のツールバーで隣り合うボタンを1つのグループに見せる間隔。チェックリストの目安12pt は枠のあるボタンどうしの間隔）。iPhone Duo の縦並びは10pt
- 無料版の残り件数の文言は、行数の上限を設けずに折り返し、省略しない（最大文字サイズや英語では3行以上になる）
- S-03 の入力欄は60文字まで。上限に達すると文字数表示を「60 / 60文字」にし、それ以上は入力できない（保存は押せる）
- 数字と単位の間には半角の空白を入れない（「30件」「残り 25件」のように、数字の前の語との間だけ空ける）。数字の後ろに助詞が続くとき（「¥480 で購入」）は、数字と助詞の間を空ける。
- 日付と時刻は、端末の地域設定と24時間表示の設定に従ってシステムの書式で作る（下の例は日本語・12時間表示のとき）。「今日」は端末の現在のタイムゾーンで決め、日記の日付は S-03 を開いた時点で決める（シートの題名の日付で保存する。0時をまたいでも変わらない）。
- 詳細に出す時刻は、その日記を最初に保存した時刻。その日のうちに書いた場合だけ表示し、後から書いた日は時刻を出さない。
- 日付は今年の分は「10月24日（土）」、去年以前の分は「2025年10月24日（金）」。一覧は年が変わるところに年の見出しを入れる

## 4. プラットフォーム別の設計

- **iPhone**： 今日を書くは右上（ツールバー）。本文は改行を含められる（S-02・iPad・Mac の詳細は改行どおりに表示）。最大文字サイズでは S-04 と許可の説明画面の見出し・説明・カードを縦にスクロールさせ、「¥480 で購入」「続ける」は下に固定して隠れないようにする（「購入を復元」とリンクはスクロールする内容の末尾へ）。S-02 のツールバーは 編集 → 削除 の順（iPad・iPhone Duo も同じ順にそろえる）。一覧は本文の改行を空白に置き換えて先頭から1行で切り、末尾を「…」にする。最大文字サイズでは日付と本文を縦に積み、本文は4行まで表示して末尾を省略する（全文は S-02 で読める）。残り件数は題名の下で折り返し、行の右端の詳細へ進む印も残す。S-03 の題名（日付）はシステムのナビゲーションバーの題名にする（文字サイズでの拡大に上限があり、長押しで拡大表示される）。最大文字サイズでは入力欄が縦に伸び、キャンセルと保存は入力欄の上に固定して隠れないようにする
- **iPhone Duo**：
  - 外側の S-02： 右端の縦の列に上から 戻る（chevron.backward）→ 削除（trash）、その下にタブバーと検索タブ。「編集」は文字のボタンなので内容の上の横のバーに残す（モックは描かない。S-01 と同じ列の構成で、上の文で足りるため）
  - 外側は右端に縦一列で、右上の丸いカメラ（Dynamic Island）から下へ ステータスバー → ツールバー（今日を書く）→ タブバー → 検索タブを並べる（位置は近似）。縦に並ぶ操作はハードウェアに合わせた位置なので、右から左の言語でも同じ側に残る。Safe Area は左右・上下で非対称として扱う
  - 場所が足りないときにあふれメニューに入る順番： 削除 → 検索。今日を書くとタブバーは最後まで残す（「…」はシステムのあふれメニュー専用で、アプリ独自の「…」は置かない）
  - 内側の Split View では、縦のバーの位置はシステムに任せる（アプリが左半分にあるときは左の端に来る。独自に右へ固定しない）
  - 内側は横向きを主にし、左に一覧ペイン、右に詳細ペイン。詳細の文字のボタン（編集）は詳細ペインの上の横のバーに置き、記号のボタン（今日を書く・削除）とステータスバーは右端に縦に並べる。完全に開いているときは一覧を狭く、半分折ったときは一覧と詳細を同じ幅にして、中央の折り目に何もかけない（`iphone-duo-inner-landscape-S-01-folded`）
  - 内側の縦向きは iPhone と同じ横向きのバー（下にタブバー）。半分折ったときに横一文字に入る折り目に、詳細のカードとボタンがかからない配置にしてある（折り目より下は一覧の続きだけ）
  - 開くと、外側で表示していた日記を内側の詳細にそのまま表示し、入力中の文章も引き継ぐ。内側の Split View（半分の幅）では一覧だけにし、選ぶと詳細に進む
- **iPad**： メニューバーの「設定…（⌘,）」はサイドバーの「設定」を選んだ状態にする。列の切り替えは上の「サイズクラスごとの列」の表。アクセシビリティサイズ（AX1〜AX5）では、横 regular でも2列まで（サイドバーは畳む）にし、一覧の行は iPhone と同じ形（日付と本文を縦に積み、本文4行まで）にする。iPhone Duo の内側も同じ。詳細の題名はツールバーの段の下に置く。ツールバーは 編集・削除・今日を書く・検索（末尾）の順。⌘N で今日を書く、⌘F で検索、⌘⌫ で削除。iPadOS 26 以降のポインタを前提にし、ツールバーのボタンはポインタが乗るとガラスのハイライト、一覧の行とサイドバーの項目は背景が淡くなる。メニューバーの項目は Mac と同じ（各タブを「表示」メニューにも入れる）
- **Mac**：
  - メニューバー： 下の表（iPad も同じ）。ショートカットは標準と衝突しない。日記を選んでいないとき・0件のときは「削除」と「日記を編集…」を淡色にして無効にし（隠さない。iPad・Mac のツールバーの「編集」と「削除」も同じ）、書き出すものがないときは「書き出す…」も淡色にする。一覧の行の長押しのメニュー（コンテキストメニュー）は、使えない項目を出さない
  - ツールバー： サイドバーの切り替え（sidebar.left、サイドバーの上端）、題名「すべての日記」と副題（残り件数）、編集、今日を書く、検索フィールド（末尾）。削除はメニューバーが常に見えるので「編集」メニューと ⌘⌫
  - ポインタが乗ると、一覧の行とサイドバーの項目は背景が淡くなり、ツールバーのボタンは枠が出る
  - フルスクリーンはシステムのもの（⌃⌘F、「表示」メニュー）を使う

- VoiceOver： 一覧の各行は「10月24日、公園の銀杏が…」の順で1つの要素として読む。ボタンのラベルは画面上の文言と同じ「今日を書く」。記号だけのボタンにもラベルを付ける（検索＝「検索」、戻る＝「戻る」、削除＝「削除」、S-04 の閉じる（xmark）＝「閉じる」、サイドバーの切り替え＝「サイドバー」（iPad・Mac）、iPhone Duo の縦並びボタンも同じ。システムのあふれメニューのラベルはシステムに任せる）。S-03 の文字数は入力欄の補足として「13文字、最大60文字」と読む。許可の説明画面のベルの絵は読まない。カレンダーの日付は「10月24日、書いた」「10月25日、まだ書いていません」と読む。S-03 の天気の記号は「晴れ」のように読み、選ばれていたら「選択中」を付ける。Watch の S-07 は 題名 →（本文と時刻をまとめて1つ）→ 同期待ちの表示（あるとき）→「音声で書く」の順に読む
