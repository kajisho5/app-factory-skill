# ひとこと日記 デザイン設計書（実例・架空のアプリ）

> hig-design-skill の実例です。アプリ名・日記の内容はすべて架空です。モックは `mocks/`（`build.py` で再生成できます）。

## 1. 前提

- アプリの目的： 1日1行だけ日記を書き、あとから読み返せるようにする
- 主な利用者と利用場面： 寝る前や移動中に、片手で短く書きたい人
- 対応プラットフォーム： iPhone / iPhone Duo / iPad / Mac（ネイティブ）/ Apple Watch
- 掲載用画像： 2台並び（pair、一覧と詳細）と、iPhone Duo の端末フレーム付き画像
- 画面の向き： iPhoneは縦固定（ウィンドウサイズの変化には追従）、iPadは全方向
- 判断原則： 書くまでの手数を最少にする ＞ 標準の見た目 ＞ 情報量
- 起動画面： S-01 の骨格だけ（背景とカードの形、文字なし、ライト／ダーク別）の Launch Screen。ロゴアニメ・広告なし。起動したら S-01 を表示
- 文言： すべて String Catalogs で管理する前提で設計書に書く
- アプリアイコン： この実例の範囲外

### 余白と寸法
- 画面端の余白はシステムのレイアウトマージン（モックでは iPhone 16〜20pt）
- リストはグループ表示（角丸のカード）。セルの高さは2行で約76pt、セル内の左右余白20pt
- ボタンはすべて44×44pt以上。ツールバーの丸ボタンの間隔は6pt以上（モックでは iPhone Duo の縦並びで10pt）
- 無料版の残り件数の文言は、英語などで長くなった場合は2行まで折り返し、省略しない
- S-03 の入力欄は60文字まで。上限に達すると文字数表示を「60 / 60文字」にし、それ以上は入力できない（保存は押せる）

## 4. プラットフォーム別の設計

- **iPhone**： 「今日を書く」ボタンは右上（ツールバー）。一覧は1行目を1行で切り、末尾を「…」にする。最大文字サイズでは日付と本文を縦に積み、本文は4行まで表示して末尾を省略する（全文は S-02 で読める）。S-03 は最大文字サイズでは入力欄が縦に伸び、キャンセルと保存は入力欄の上に固定して隠れないようにする
- **iPhone Duo**： 外側は右端に縦一列で、右上の丸いカメラ（Dynamic Island）から下へ ステータスバー → ツールバー（「今日を書く」、検索。記号のボタン）→ タブバー（日記／カレンダー／設定）を並べる（位置は近似）。内側は横向きを主にし、左に一覧ペイン（上にサイドバー切り替え）、右に詳細ペイン。詳細の操作とステータスバーは右端に縦に並べる。完全に開いているときは一覧を狭く、半分折ったときは一覧と詳細を同じ幅にして、中央の折り目に何もかけない（`iphone-duo-inner-landscape-S-01-folded`）。内側の横向きでもタブバーは右端の下寄せに縦に並べる。内側の縦向きは横向きのバーで、半分折ったときに横一文字に入る折り目に詳細のカードがかからない配置にしてある（折り目より下は一覧の続きだけ）。開くと、外側で表示していた日記を内側の詳細にそのまま表示し、入力中の文章も引き継ぐ。内側の Split View（半分の幅）では一覧だけにし、選ぶと詳細に進む
- **iPad**： 横向きはサイドバー＋一覧＋詳細の3列。細いウィンドウではサイドバーを畳み、一覧＋詳細の2列、さらに狭ければ一覧のみ。⌘N で新規作成、⌘F で検索。メニューバーにも同じコマンドを出す
- **Mac**： メニューバーはアプリ名・ファイル・編集・表示・ウインドウ・ヘルプ。ショートカットは ⌘N 新規作成、⌘F 検索、⌘, 設定（標準と衝突しない）。ウィンドウの最小幅は一覧＋詳細が並ぶ幅。ツールバーは検索フィールドと「今日を書く」ボタンの2つだけ
- **Apple Watch**： 今日のひとことと「音声で書く」だけを表示する。コンプリケーションは今日書いたかどうか（円形の小さい型はチェックの記号だけ、長方形の型は「今日：記録済み／未記録」）。常時表示では本文を隠し「記録済み」とだけ表示する（`watch-ultra-S-01-aod`）。iPhoneが近くにないときは端末に保存し、あとで同期する

## 5. アクセシビリティ
- VoiceOver： 一覧の各行は「10月24日、公園の銀杏が…」の順で1つの要素として読む。ボタンのラベルは画面上の文言と同じ「今日を書く」。記号だけのボタンにもラベルを付ける（検索＝「検索」、戻る＝「戻る」、iPhone Duo の縦並びボタンも同じ）
- 視差効果を減らす： シートの表示はクロスフェードにする
- 透明度を下げる： タブバーとサイドバーは不透明な背景にする
