あなたはiOSアプリ開発のエキスパートです。以下の仕様で、新規アプリ「宛名印刷 はがき・封筒」をゼロから開発してください。

## 背景とコンセプト

年賀状や挨拶状の宛名印刷アプリは需要が大きい一方、既存アプリは広告が多く、印刷直前に課金画面を挟むものが目立ちます（対象競合は評価3.59、レビュー844件、低評価の不満は広告10件・課金2件が中心）。本アプリはその不満を潰しにいきます。

- 広告なし（広告SDKを一切入れない）
- サブスクなし（あるのは買い切りの一回払いだけ）。印刷の直前など、作業の佳境で課金画面を出さない
- 住所録CSVの取り込みに対応し、年賀状シーズンに大量の宛先を一括登録できる
- 住所データは端末内のみに保存し、外部サーバーに送らない

判断に迷ったら、この原則に反しない方を選んでください。

## 技術条件

- SwiftUI + Swift（最新の安定版）、iOS 17.0以上、iPhone / iPad対応。Macは「Designed for iPad」で動作する前提（Mac専用UIは作らない）
- サードパーティライブラリ禁止（Apple純正フレームワークのみ）
- データ保存は SwiftData、印刷は AirPrint（UIPrintInteractionController）、PDF出力は UIGraphicsPDFRenderer
- 課金は StoreKit 2、非消耗型のアプリ内課金1点のみ
- Xcodeでそのまま開いてビルドできる形で納品すること（XcodeGenの project.yml 方式でも可。その場合は生成手順をREADMEに明記）
- UIは日本語。コード内の識別子とコメントは英語
- **UIデザインはAppleの Human Interface Guidelines (HIG) に必ず沿うこと。** タップ領域（44pt以上）、Safe Area、Dynamic Type、ダークモード、SF Symbolsの使い方など、HIGから外れるUIを勝手に作らない。HIGと自分の判断が衝突したらHIGを優先し、その旨を報告する
- 画面の向き: iPhoneは縦向き固定（回転対応しない）。iPadは回転・画面分割（Split View / Stage Manager）に対応し、レイアウトが崩れないこと。印刷プレビューはiPadの横向きで用紙全体が見えるレイアウトにする
- 標準対応（必須）: ダークモード（色はアセットカタログで定義し、両モードで表示確認）／ Dynamic Type（最大文字サイズでもレイアウトが崩れない）／ 主要操作へのVoiceOverラベルとコントラスト比の確保 ／ UI文字列は String Catalogs（.xcstrings）で管理しハードコードしない ／ 権限拒否時の代替導線（設定アプリへの誘導）とデータ空状態の画面を用意する ／ プライバシーマニフェスト（PrivacyInfo.xcprivacy）を用意し必須理由APIを申告する ／ 住所データはiCloudバックアップ対象とし、アップデートや機種変更で消えない設計にする
- 追加の標準対応: 住所入力などのフォーム入力時は、ソフトウェアキーボードで入力項目や確定ボタンを隠さない ／ 起動画面はシンプルにし、広告・ロゴアニメ・待機演出を入れない ／ iPhoneでは主要アクションを画面の下部〜中部に置き、シートの開閉操作を一貫させる ／ iPadでは画面幅を活かしたレイアウト（宛先リスト＋プレビューの2ペインなど）にし、ポインタとハードウェアキーボードに対応する

## 機能仕様

### 1. 宛先リスト
- 宛先の登録・編集・削除: 氏名、連名（配偶者など）、敬称（様/先生/御中などのプリセット＋自由入力）、郵便番号、住所、メモ（喪中・転居先など）
- iPhoneの連絡先から取り込み（Contactsフレームワーク）
- **CSV取り込み**: 氏名/連名/郵便番号/住所/メモ の列を持つCSVを読み込む。取り込み前にマッピング確認画面を出す。テンプレートCSVを共有シートで書き出せること
- グループ分け（例: 年賀状2026、仕事関係）と、グループ単位の一括印刷
- 印刷済みフラグと印刷日時の記録（出し忘れ・二重印刷の防止）

### 2. レイアウト
- 用紙: はがき（100×148mm、年賀はがき含む）、封筒 長形3号・長形4号・洋形2号・角形2号
- 縦書き・横書きの両対応。縦書き時は住所の数字を漢数字へ自動変換するオプション（例: 1-13-3 → 一-一三-三 ではなく「一丁目十三番三号」形式への変換は不要。数字の漢数字置換のみでよい）
- 郵便番号は赤枠位置に合わせて自動配置（はがき印刷の定位置）
- 差出人（自分の住所・氏名）を登録し、宛名面への印刷ON/OFFを切り替え
- フォントは明朝・ゴシックなど数種類から選択、文字サイズは住所の長さに応じて自動調整（はみ出し時は警告表示）
- 印刷位置の微調整（上下左右をmm単位でオフセット調整し、設定として保存）

### 3. プレビューと印刷
- 実寸に近い印刷プレビュー（用紙の枠と郵便番号枠を表示）
- 1件印刷と、グループの一括連続印刷
- PDFとして書き出して共有・保存も可能

### 4. 課金
- 無料版: 宛先登録10件まで。印刷機能そのものは無制限（透かし等は入れない）
- 「Pro（買い切り）」¥800 の非消耗型IAP 1点で、宛先無制限＋CSV取り込み＋PDF出力を解放
- 課金画面に「これは買い切りです。毎月・毎週の支払いは発生しません」「広告は今後も入れません」と明記する
- 無料お試し・期間限定価格など誤認させる表現は使わない。購入ボタンには価格をそのまま表示
- 購入の復元（リストア）ボタンを課金画面と設定画面の両方に置く

### 5. 設定・その他
- 差出人プロフィールは複数登録可（自宅用・仕事用）
- レビュー依頼は、印刷成功が5回を超えた後の自然なタイミングで1回だけ
- プライバシーポリシーと利用規約のリンク欄（URLは定数ファイルに切り出す）

## 権限とプライバシー

- 連絡先の用途説明文: 「宛名印刷のために連絡先へアクセスします。連絡先の内容が外部に送信されることはありません」
- トラッキングなし（ATTダイアログを出さない）、解析SDKなし
- App Privacy（プライバシーラベル）が「データを収集しない」になる設計にすること

## 進め方

1. 最初に、プロジェクト構成と画面遷移の設計だけを提示し、私の確認を待つ
2. 以後は ①宛先リストとCSV取り込み ②レイアウトとプレビュー ③印刷とPDF ④課金 ⑤仕上げ の順に実装し、各ステップでビルドが通ることを確認してから次へ進む。年賀状シーズン（11〜12月）に間に合わせるため、コアの印刷フロー（①〜③）を最優先する
3. 仕様に書いていない判断が必要になったら、勝手に範囲を広げず、選択肢と推奨案を提示して確認する

## アイコンとデモモック

- アプリアイコンは **kajisho5/fresnel**（Liquid Glassアイコン作成ツール、GitHub: kajisho5/fresnel）で作成し、iOSの **Liquid Glass** スタイルのレイヤードアイコン（.iconバンドル）として、iPhone / iPadの必要サイズを全て書き出す。ライト／ダーク／ティントの外観バリアントも用意する。デザインはHIGのアイコン指針に従う（文字を入れない、シンプルなグリフ）
- デモ用の画面モックを用意する: **iPhone / iPad / Mac / iPhone Duo（iPhone 2台並び）**（Macは Designed for iPad の画面で可）。主要画面を実機フレームで表示し、App Store掲載素材に転用できる品質にする
- アイコンの書き出しとモックは、SVG原版に加えて **PNGプレビューを必ず添えること**（確認はiPhoneで行うため、SVGだけでは見られない）
- iPhone Duoは2画面の状態（時刻・データ・選択状態・ライト／ダーク）を一致させ、役割分担が分かる並びにすること
